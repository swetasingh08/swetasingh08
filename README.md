### 🌡️ UHI Dashboard | Urban Heat Island Monitoring System

**Tech Stack:** React, Flask, Google Earth Engine, Deck.gl, MapLibre/Mapbox, Tailwind CSS, Gemini AI, Docker, Vercel, Render

- 🛰️ Built a geospatial analytics platform using Google Earth Engine to process satellite data for Urban Heat Island (UHI) detection.
- 🌍 Developed interactive map-based visualizations using Deck.gl and MapLibre for LST, NDVI, and land-use layers.
- 📊 Implemented a Flask backend to serve geospatial APIs with real-time satellite data processing and analysis.
- 🧠 Integrated Gemini AI to generate intelligent environmental insights, hotspot interpretations, and urban heat mitigation recommendations (like greening strategies and cool roof suggestions).
- 🧪 Added scenario-based simulation engine to analyze urban greening, cool roofs, and temperature reduction strategies.
- ☁️ Deployed frontend on Vercel and backend on Render using a decoupled, scalable architecture with Docker support.
